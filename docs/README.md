# FairShare — Internal Developer Specifications

This project implements the native Android FairShare product based on three authoritative specification documents:

- **[Product Requirements Document (PRD)](../specs/PRD.md)**: Product scope, deterministic financial rules, integer minor-unit money handling, and local-first architecture.
- **[Design Specification](../specs/Design.md)**: Android visual language ("Ink + Paper + Signal"), flat color tokens, Roboto typography, 4dp grid, and strict prohibition on AI-slop / gradients / glassmorphism / Lucide / Inter.
- **[Execution Plan](../specs/Plan.md)**: Step-by-step phased engineering roadmap from Phase 0 to Phase 16.
- **[Forbidden Design Patterns](FORBIDDEN_PATTERNS.md)**: Explicit list of banned visual patterns.
